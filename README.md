## 📋 General Flashing Instructions

1. **Unlock & Prepare:** Ensure your device has an unlocked bootloader and a compatible custom recovery installed.
2. **Download Package:** Grab the latest `.zip` ROM package and any required add-ons (such as GApps or auxiliary patches) from the **[Releases](../../releases)** section.
3. **Boot to Recovery:** Power off your device and boot into recovery mode using the standard hardware key combination (`Volume Up + Home + Power`).
4. **Wipe Partitions:** Perform a clean wipe (`Dalvik/ART Cache`, `System`, `Data`, `Cache`).
5. **Flash Files:** 
   * Flash the ROM ZIP package.
   * Flash GApps or additional patches if needed.
6. **Reboot:** Wipe cache/dalvik one last time and reboot to your system.
